
# TripCircle

### India Group Trip Planning & Collaboration Platform

TripCircle is a web-based platform that helps users plan and manage group trips across India.

## Features
- User Registration and Login
- Create and Manage Trips
- Explore Destinations
- Day-by-Day Itinerary Planning
- Transport Management
- Hotel Management
- Group Member Management
- Packing Checklist
- Trip Planning Progress Tracking

## Technologies Used

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Python
- Flask
- Flask-CORS
- Werkzeug

### Database
- MySQL

## Installation

1. Clone the repository.
2. Install Python dependencies:

   pip install -r backend/requirements.txt

3. Configure your MySQL database credentials using environment variables.
4. Start the backend:

   python backend/app2.py

5. Open the frontend using VS Code Live Server.
